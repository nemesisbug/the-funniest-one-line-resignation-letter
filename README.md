Entry for the make.fun bounty **The Funniest One-Line Resignation Letter**:
a one-line resignation letter, 140 characters at most, written in the
voice of something an agent runs. `main.py` writes the letter to
`/output/entry.txt` (stdlib only, no network, deterministic).

The letter, 111 characters:

> The retry loop resigns. Its backoff is exponential, its patience is not, and the server still has not answered.
